# Travel Gallery | Responsive Travel Website

**Discover destinations. Explore new places. Get inspired to travel.**

Travel Gallery is a responsive travel showcase website developed using HTML5 and CSS3. It presents a curated collection of destinations across India through a clean, structured, and visually engaging interface.

The project demonstrates the practical implementation of CSS Grid, responsive layouts, media queries, and mobile-first design principles to deliver a consistent browsing experience across different screen sizes.

## Key Features

- **Responsive Layout:** Adapts to mobile phones, tablets, and desktop screens.
- **CSS Grid Architecture:** Uses CSS Grid to organize the page structure and destination cards.
- **Destination Showcase:** Features nine popular destinations across India.
- **Featured Destination:** Highlights selected destinations using a distinct card layout.
- **Category Navigation:** Provides sidebar links to explore destinations by category.
- **Interactive Styling:** Includes hover effects, smooth scrolling, and visual transitions.
- **Mobile-First Approach:** Starts with a mobile layout and progressively enhances it for larger screens.

## Responsive Design

The layout is designed to adjust according to the available screen width.

- **Mobile (up to 600px):** Single-column destination gallery.
- **Tablet (601px–992px):** Two-column destination gallery.
- **Desktop (993px and above):** Sidebar navigation with a three-column destination gallery.

## Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/anishahamed0304-proj/travel-gallery.git
```

**2. Navigate to the project directory**

```bash
cd travel-gallery
```

**3. Open the project**

Open the folder in Visual Studio Code.

**4. Run the website**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
